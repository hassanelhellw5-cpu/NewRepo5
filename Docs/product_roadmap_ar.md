# خارطة تطوير Qemma — تجربة ممتعة وربحية بدون إعلانات مزعجة

الهدف: Qemma يبقى مكان واحد للماتشات، اللايف، التوقعات، المجتمع، والإنجازات. الربح يكون من حاجات المستخدم **عايزها ومبسوط يدفع فيها**: تخصيص، مسابقات اختيارية، مزايا اجتماعية، وتجربة تنظيمية أقوى — بدون إعلانات، بدون أفلييت، وبدون pay-to-win.

## مبادئ المنتج
- اللايف والمحتوى الأساسي يفضلوا واضحين وسهلين ومش محجوبين ورا دفع.
- أي دفع لازم يبقى اختياري ويزود المتعة أو الشكل أو التنظيم، مش يظلم المستخدم المجاني.
- ممنوع popups فوق اللايف؛ أي لعبة أو تحدي يكون من تاب/زر اختياري.
- كل ميزة مدفوعة لازم تبقى مفهومة قبل الدفع وفيها قيمة مباشرة.

## Phase 1 — تثبيت التجربة الأساسية والثقة
### للمستخدم
- تشغيل اللايف بسيرفرات متعددة لكل قناة مع fallback تلقائي عند تعطل سيرفر.
- صفحة حالة للماتش تعرض: السيرفر الحالي، عدد السيرفرات المتاحة، وهل اللايف شغال أم مقفول.
- زر "جرّب سيرفر تاني" واضح داخل المشغل.
- إزالة أي أسئلة أو popups تظهر فوق اللايف تلقائيًا.
- صفحة ماتش متكاملة: النتيجة، الوقت، القناة، التشكيل، الأحداث، الترتيب، والستريمات.

### للربح بدون إزعاج
- باقة Supporter شهرية اختيارية بسعر بسيط تعطي شكل خاص فقط: Badge، لون اسم، إطار كومنت، وأيقونة داعم.
- لا يوجد أي حجب للايف أو للماتشات عن المستخدم المجاني.

### مؤشرات نجاح
- تقليل فشل تشغيل اللايف.
- زيادة متوسط وقت المشاهدة.
- زيادة رجوع المستخدم في نفس اليوم.

## Phase 2 — دوريات التوقعات المجانية والـ Knockout
### للمستخدم
- إنشاء الدوريات الخاصة مجانًا بالكامل بدون رسوم إنشاء أو دخول.
- كل دوري له كود دعوة، ترتيب نقاط، وسجل توقعات.
- نظام نقاط واضح: توقع الفائز، توقع النتيجة الصحيحة، توقع فارق الأهداف.
- زر في الداشبورد يحول الدوري من ترتيب عادي إلى Knockout بناءً على ترتيب النقاط الحالي.
- Knockout rounds: الأعلى نقاطًا يعدّي، وعند التعادل يكسب صاحب seed الأعلى.
- جائزة افتراضية للفائز في Knockout: 100 نقطة داخل الدوري.

### للربح بدون إزعاج
- League Customization Pack: صاحب الدوري يشتري شكل للدوري فقط، مثل كأس خاص، لون صفحة الدوري، شعار، أو خلفية.
- Private League Plus: مزايا تنظيمية اختيارية مثل عدد أعضاء أكبر، تاريخ موسم، export للترتيب، وإحصائيات أعمق.
- لا يوجد شراء نقاط ولا مضاعفة نقاط؛ الدفع لا يؤثر على الفوز.

### مؤشرات نجاح
- عدد الدوريات المنشأة.
- نسبة دعوات الأصدقاء الناجحة.
- عدد الدوريات التي تتحول إلى Knockout.

## Phase 3 — مجتمع اللايف بدون مقاطعة
### للمستخدم
- شات لايف لكل ماتش مع رسائل تشجيع جاهزة.
- Reactions سريعة أثناء الماتش: هدف، فرصة، إنقاذ، ظلم تحكيمي.
- تحديات اختيارية لا تظهر فوق الفيديو: المستخدم يفتحها من تاب منفصل لو حابب.
- Badges مجانية وموسمية للمستخدمين النشطين.
- Match Rooms: غرفة لكل ماتش فيها شات، توقعات، وتصويتات اختيارية.

### للربح بدون إزعاج
- مدفوعات شكلية للشات: ستكرات، إيموجيز فريق، ألوان اسم، وإطارات.
- Pin Message اختياري لمدة قصيرة بكوينز، مع حدود تمنع الإزعاج.
- Fan Profile Premium: بروفايل أجمل، إحصائيات أكثر، badges عرض أكثر.

### مؤشرات نجاح
- رسائل الشات لكل ماتش.
- عدد المستخدمين الذين يتفاعلون بدون مغادرة اللايف.
- مبيعات العناصر الشكلية.

## Phase 4 — مسابقات رسمية وتجربة موسمية
### للمستخدم
- بطولات توقعات أسبوعية رسمية مجانية بجوائز نقاط وbadges.
- صفحة إنجازات: أطول سلسلة توقعات صحيحة، أفضل مركز، عدد المشاركات، أفضل دوري.
- Leaderboards عامة وخاصة: اليوم، الأسبوع، الشهر، البطولة.

### للربح بدون إزعاج
- Premium Prediction Cups اختيارية: دخول بكوينز أو تذكرة مدفوعة، بجوائز شكلية/نقاط/اشتراك Supporter.
- Team Packs: حزم شكلية لمشجعي فرق معينة، مثل theme وأيقونات وbadges.

### مؤشرات نجاح
- عدد المشاركين في المسابقات الأسبوعية.
- شراء Team Packs والعناصر الشكلية الموسمية.

## Phase 5 — محتوى وإحصائيات تجعل الموقع مرجعًا
### للمستخدم
- مركز إحصائيات لكل فريق ولاعب: آخر النتائج، هدافين، تشكيلات، مواجهات مباشرة.
- توصيات ذكية للماتشات المهمة اليوم.
- ملخص بعد الماتش: النتيجة، الأحداث، أفضل لاعب، ترتيب التوقعات.
- Archive للماتشات والهايلايت إن كان متاحًا قانونيًا ومصدره مسموح.

### للربح بدون إزعاج
- Pro Stats اختياري لمحبي التحليل: إحصائيات أعمق، مقارنة فرق، وتاريخ توقعات مفصل.
- Export وتقارير للدوريات الخاصة الكبيرة.
- Custom Tournament Hosting: تنظيم بطولة توقعات خاصة لمجتمع/جروب مقابل رسوم تنظيمية.

### مؤشرات نجاح
- زيارات صفحات الإحصائيات.
- تحويل مستخدمين Pro Stats.
- عدد البطولات الخاصة المدفوعة.

## Phase 6 — تطبيق ومزايا ولاء
### للمستخدم
- Push notifications اختيارية: بداية ماتش، هدف، تذكير توقع قبل المباراة.
- Wallet واضح للنقاط والكوينز والbadges.
- Daily streak للتوقعات بدون إلزام مزعج.

### للربح بدون إزعاج
- اشتراك Supporter سنوي بسعر أفضل.
- متجر موسمي لعناصر محدودة وقت البطولات الكبرى.

### مؤشرات نجاح
- retention أسبوعي وشهري.
- الاشتراكات السنوية.

## أفكار ربحية مرفوضة لأنها مزعجة أو مضرة
- إعلانات فيديو قبل اللايف أو فوق المشغل.
- Affiliate betting أو روابط مراهنات.
- بيع نقاط تؤثر على ترتيب التوقعات.
- Popups إجبارية أثناء الماتش.
- إجبار المستخدم يدفع عشان يشاهد اللايف الأساسي.

## أولويات تنفيذ سريعة
1. صفحة حالة اللايف وسيرفراته.
2. UI للدوريات الخاصة المجانية.
3. زر تحويل الدوري إلى Knockout في الداشبورد.
4. صفحة bracket للـ Knockout.
5. متجر بسيط للـ badges/themes.
6. نظام Supporter اختياري.
7. Pro Stats وPremium Analytics للدوريات.
8. Custom Tournament Hosting لاحقًا بعد استقرار الدوريات.
